Contributor checklist when adding or updating a language
  1. Keep {placeholders} (such as {title}, {size}, {max}, {count}, {name}) and <a> links intact.
  2. Save your file under locales/<code>.js with const <code> = { ... };.
  3. For a new language, register it in index.html, scripts/languages.js, scripts/clock.js, README.md, and tools/translationTool.html.
  4. Test visually in Chrome & Firefox. Verify humidity/menu widths don't wrap.
