v3.3.1126 CURRENT

  • Added customizable shortcuts for AI Tools (Alt + A), To-Do (Alt + T), Settings (Alt + O), Google Apps, and Voice Search, with Alt-hold badges and Alt + 1–9 support for expanded AI Tools.

v3.3.1125

  • Added an option to add bookmarks to shortcuts.
  • Added an option to add custom AI tool shortcuts.
  • Redesigned the bookmarks UI with an improved layout, new options, and additional sort modes (Browser order, Z–A, and New–Old).
  • Added the ability to create new bookmarks and choose a folder when adding or editing them.
  • Added an option to favorite bookmarks.
  • Added a customizable Alt + B shortcut to open the bookmarks sidebar.

v3.3.1115

  • Added support for Armenian language.
  • When entering a link, the search bar now opens the website directly instead of searching for it.
  • Added a Google AI Mode search button to the search bar when using Google as the search engine.
  • Quickly open your shortcuts with keyboard shortcuts. Use Alt + 1 through Alt + 9 to open the first nine shortcuts.
